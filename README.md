# Brightside Studio — three-page website

A responsive, three-page small-business website built with plain HTML, CSS, and JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About
- `contact.html` — Contact form

## Run locally
1. Extract the ZIP file.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build tools or package installation are required.

## Included
- Responsive navigation with a mobile menu
- Shared stylesheet and JavaScript
- Semantic page structure and basic SEO descriptions
- Contact form validation and a Gmail compose handoff with the message pre-filled
- Automatic footer year
- Reduced-motion accessibility support

## Before delivering to a real client
- Replace the fictional Brightside Studio name, copy, and demo contact address (`hello@brightside.example`) with the client's real details.
- The contact form opens a pre-filled Gmail compose window; the visitor must review and send the email. It does not store or send submissions automatically.
- Confirm the client's preferred fonts, colors, images, and final text.
- Test all three pages on mobile and desktop.
